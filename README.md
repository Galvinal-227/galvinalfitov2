## 📦 Installation

Clone the repository.

```bash
git clone https://github.com/Galvinal-227/galvinalfitov2.git
```

Go to the project folder.

```bash
cd galvinalfitov2
```

Install dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```

Build for production.

```bash
npm run build
```

Preview production build.

```bash
npm run preview
```
